# ⏱️ Stopwatch Web App

A simple yet elegant **Stopwatch** built using **HTML, CSS, and JavaScript**. Start, stop, and reset your timer with smooth controls and a responsive design.

---

## 🧩 Features

- 🟢 Start / 🔴 Stop / 🔁 Reset buttons
- ⏲️ Accurate time tracking (minutes, seconds, milliseconds)
- 🎨 Minimal and clean UI
- 📱 Fully responsive design

---

## 🛠️ Built With

- HTML
- CSS
- JavaScript

---

## 💡 How It Works

- **Start** begins the timer
- **Stop** pauses the time
- **Reset** sets it back to zero

Under the hood, it uses `setInterval()` to count milliseconds and displays time with real-time updates.
